# markstrom/homebrew-tap

Homebrew casks for apps by Anders Markström.

## Sorla

Swedish push-to-talk dictation for the Mac, fully on-device. <https://sorla.zerolabs.se>

```sh
brew install --cask markstrom/tap/sorla
```

Update with `brew upgrade --cask sorla`. Requires a Mac with Apple Silicon and macOS 14 or later.
